Troubleshooting

CLI not found on the Mac

Install the relevant official CLI (claude, codex, grok or agy for Antigravity) using that provider’s instructions. Confirm it opens in Terminal, then reopen the helper and refresh. The helper checks common install locations and your login-shell PATH; its Transparency view shows which executable it found. A moved, missing or non-executable installation will not be used.

A separate account config folder does not install a CLI. If you use an unusual installation location, check the helper’s detection status before changing anything. Do not copy credentials into Quotabell.

Signed out or the wrong Mac account

Open the provider’s official CLI and sign in using its own flow, then refresh Quotabell. The helper uses whichever account that CLI is currently signed into. For multiple Mac accounts, sign each CLI into its intended separate config folder and select that folder in helper Settings → Accounts. A nickname alone does not switch a CLI login. Quotabell passes the path to the CLI without opening the folder.

Antigravity CLI shows no usage on the Mac

Install Antigravity CLI using Google’s instructions, run agy in Terminal and sign in with its own flow, then refresh Quotabell. The helper needs agy 1.1.11 or later, which has the built-in read-only usage report; update agy if the helper reports an unsupported version. Antigravity on the Mac always uses the current agy sign-in, so separate config folders and Wake are not available for it.

Antigravity reports quota per model group. The main tiles show the Gemini group; other reported groups appear as separate windows. If your account only reports a weekly limit, no 5-hour limit is shown.

iCloud is off, or the phone is waiting

For Mac-helper accounts, sign into the same Apple Account on both devices and enable iCloud access for Quotabell. Keep the helper running and the Mac awake and online. Check its iCloud status, then use Check again in the iPhone’s Setup & Status. Give iCloud time to deliver a new reading. The helper’s default check interval is five minutes; failures can back off.

Phone-only accounts do not need the Mac helper or CloudKit quota sync. Their optional iCloud Keychain setting is separate. If you just want to explore the interface, enable Show sample data in Setup & Status.

Widget not updating or missing an account

Open Quotabell on the iPhone and refresh first. Check that the account is visible in the app, has data and is included in the widget’s account selection. Touch and hold the widget to edit its configuration; Auto and a single-account selection show different views. Medium, large and rectangular layouts can list selected accounts and show an overflow count when they do not all fit.

For Mac-helper accounts, also check iCloud and the Mac’s last update. For phone-only accounts, check that you are signed in. iOS controls widget and background refresh timing, so updates are not immediate or guaranteed. If the app is current but the widget remains stale, remove and add the widget again.

Phone-only sign-in does not complete

Read the risk sheet first. The primary flow uses Apple’s sign-in sheet as the provider’s official CLI app. Check your connection and the provider account selected in the sheet. Claude has a manual code fallback when offered; ChatGPT / Codex needs its sign-in redirect to return to the app; Grok uses a device-code approval flow; Antigravity uses Google sign-in in Apple’s sheet and returns to the app on the iPhone itself. If the session expires, start again rather than sharing a code with anyone.

Antigravity has no website fallback. If “Other sign-in options” is used for another provider, passkeys and Google sign-in do not work in its embedded website view. Use an available email/password method or the main sign-in flow, or switch to the Mac helper. Grok’s website fallback is foreground-only and shows chat limits rather than the weekly pool.

Endpoints and permissions can change. If access is refused, do not repeatedly retry to evade it. A rate-limit response causes back-off; wait before trying again. You can Sign Out to remove saved tokens. The Mac helper remains the safer option.

Numbers look old or a reset has passed

Read the “as of” time: Quotabell can retain the last successful reading after a failed check. A countdown reaching zero is not proof of renewed quota; a fresh provider reading is needed. Refresh, check the account’s source and compare with the provider’s own usage display. Some sources, including Claude.app’s usage-history fallback, do not provide reset times.

No notification, or two devices both notify

Enable alerts in Quotabell and allow notifications in system settings. Check Focus and notification previews. Existing low windows are recorded silently when you enable alerts; only subsequent threshold changes notify. Alerts need a fresh usable reading, so background delays can delay or suppress them. Reset alerts require an earlier warning for that 5-hour window and a fresh reset reading; weekly reset alerts are off.

Mac and iPhone alerts are independent. If both are enabled, both can notify. Choose the device you prefer. There is no server coordinating notifications.

Wake says “start not confirmed”

Wake runs only on the Mac, is off by default, and uses a small amount of your plan. Scheduled runs skip active windows. After a message, the helper checks subsequent quota reads for up to 15 minutes; if it cannot confirm a new window, it reports that honestly. Keep the Mac awake and signed into the CLI. Errors pause Wake for the day. Grok and Antigravity have no Wake.

Common questions

Which limits can I see?

Claude and ChatGPT / Codex show the 5-hour session and weekly limits reported for your plan, with percent left and reset countdowns when available. Claude model-specific weekly limits appear when reported. Grok / SuperGrok’s main data source has a weekly pool only. Antigravity CLI shows the 5-hour and weekly limits it reports for each quota group. Availability depends on your provider and plan; Quotabell cannot create a limit the provider does not report.

Do I need a Mac?

The default, safer mode uses the free Mac helper, the provider’s official CLI and the same Apple Account with iCloud on your Mac and iPhone. You can instead opt into phone-only sign-in for individual accounts after reading its risk disclosure. The iPhone app requires iOS 26 or later; the helper requires macOS 26 or later.

Is Quotabell free?

Version 1 is free, including the Mac helper. There are no ads, analytics or tracking, and no account to create with LAZSOL. Your provider’s plan and terms still apply. Optional Wake uses a small amount of that plan.

How often does it update?

The Mac checks every five minutes by default, with back-off after failures. The iPhone refreshes when opened and when iOS permits background work. Widget refreshes are scheduled by iOS. Numbers and alerts can be delayed: check the last-updated time and the provider’s own usage page when timing matters.

Can I add Work and Personal accounts?

Yes. Add multiple accounts per provider and give each a nickname. Phone-only accounts have separate Keychain sign-ins. Mac accounts use the CLI’s current login, or an advanced per-account config folder; you must sign the official CLI into that folder yourself (not available for Antigravity). Quotabell only passes its path to the CLI and never opens the folder.

Does checking usage send a chat?

Normal quota checks do not chat or run models. Wake is the explicit exception: if you enable it on the Mac, it sends one tiny message through your own Claude or Codex CLI at a chosen time and uses a small amount of your plan. It is off by default.
